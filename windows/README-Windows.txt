试卷清晰化 · ClearPaper（Windows 免安装版）
============================================

适用：Windows 10 / 11，64 位。免安装、全离线、数据不出本机。

怎么用
------
1. 把整个 ScanClean 文件夹解压到任意位置（不要只拖出里面的单个文件）；
2. 把试卷 PDF 拖到 ScanClean.bat 上（可一次拖多个）；
3. 稍等，结果出现在原 PDF 同目录：<原名>-清晰版.pdf
   若原目录不可写，会改存到  文档\试卷清晰版\

输出是标准 A4（210×297mm）。打印时选「A4 + 实际大小(100%)」，不要选“适合页面”。

说明
----
- 内置 Python 与全部依赖（PyMuPDF / numpy / Pillow / scipy），无需安装任何东西；
- 全程离线，不上传任何文件；
- 首次运行若弹出「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」；
- 本工具是脚本 + 便携解释器，没有安装程序、不写注册表，删掉文件夹即卸载。
